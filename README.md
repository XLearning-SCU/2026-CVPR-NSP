## Data Preparation

**Training data**: The noisy images in SIDD Medium (sRGB).  
**Testing data**: SIDD Validation (sRGB), SIDD Benchmark (sRGB), and DND (sRGB).

2. Convert the `.mat` files of SIDD Validation and Benchmark to `.png` images by running `python mat2folder_sidd.py`.
3. **`Note:`** The directory structure of SIDD dataset should be as follows.

## Training
To train NSP(DBSN) and NSP(TBSN), run the following commands respectively:  
`sh train_nsp_dbsn.sh`  
`sh train_nsp_tbsn.sh`  

**`Note:`** The results reported in the paper were obtained by random seed initialization. To ensure the exact reproducibility, we have retrained NSP (DBSN) and NSP (TBSN) using fixed seeds, which are set as the default in the released code. The updated results are presented in the table bellow. The corresponding logs are respectively shown in `raw_nsp_dbsn.txt` and `raw_nsp_tbsn.txt`. All pretrained models (with and without fixed seeds) are available on the `ckpts/` folder of [Google Drive](https://drive.google.com/drive/folders/1Fa4Z5mZJ7EuVbpPfzKLBc63ToQlImhJs?usp=sharing).  
The training results may be ***slightly*** different on other machines. It is **up to you** to choose which results as the baseline in your work.  

| Method | Random seeds<br><span style="font-weight: normal; font-size:0.8em">(reported in the paper)</span> | Fixed seeds |
| :--- | :---: | :---: |
| NSP (DBSN) | 37.02 / 0.8865 | 37.05 / 0.8880 |
| NSP (TBSN) | 37.12 / 0.8853 | 37.28 / 0.8888 |



## Testing
Download the pretrained models from [Google Drive](https://drive.google.com/drive/folders/1Fa4Z5mZJ7EuVbpPfzKLBc63ToQlImhJs?usp=sharing) and place them in `./ckpts/`.

#### Testing on SIDD Validation
To test NSP(DBSN) and NSP(TBSN) on SIDD Validation, run the following commands:  
`python test_sidd_v_dbsn.py`  
`python test_sidd_v_tbsn.py`  


#### Testing on SIDD Benchmark
1. First, run `python test_sidd_b_dbsn.py` or `python test_sidd_b_tbsn.py` to get the denoised images.
2. Suppose the denoised images are saved in `folder_path`, then run `python SIDDBen_folder2csv.py folder_path` to generate `SubmitSrgb.csv` (approximately 320MB).
3. Finally, upload the `SubmitSrgb.csv` to the websites on Kaggle, i.e., [SIDD_Benchmark_PSNR](https://www.kaggle.com/competitions/sidd-benchmark-srgb-psnr/submissions) and [SIDD_Benchmark_SSIM](https://www.kaggle.com/competitions/sidd-benchmark-srgb-ssim/submissions), to test the PSNR and SSIM respectively.
4. **`Note:`** The `SubmitSrgb.csv` files of NSP(DBSN) and NSP(TBSN) can be found at [Google Drive](https://drive.google.com/drive/folders/1Fa4Z5mZJ7EuVbpPfzKLBc63ToQlImhJs?usp=sharing). Their performances should be `37.4182 / 0.874833` and `37.4580 / 0.874363`, respectively, as reported in the paper.


#### Testing on DND
1. First, run `python test_dnd_dbsn.py` or `python test_dnd_tbsn.py` to get the denoised images.
2. Suppose the denoised images are saved in `folder_path`, then run `python DND_folder2mat.py` to generate the `.mat` files located at `folder_path/dnd_submit_files/bundled/*.mat`.
3. Finally, upload the `*.mat` files to the `Submit` button in the [DND official website](https://noise.visinf.tu-darmstadt.de/).
4. **`Note:`** The `*.mat` files of NSP(DBSN) and NSP(TBSN) can be found at [Google Drive](https://drive.google.com/drive/folders/1Fa4Z5mZJ7EuVbpPfzKLBc63ToQlImhJs?usp=sharing). Their performances should be `37.7963/0.9319` and `37.8747 / 0.9342`, respectively, as reported in the paper.
